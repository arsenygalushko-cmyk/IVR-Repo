**[ ПРОБЛЕМНОЕ ПОЛЕ ]**  
Описание проекта

Количество школьников, участвующих в олимпиадах по информатике, постоянно растёт, что приводит к необходимости развития и совершенствования платформ, предназначенных для подготовки к ним. К таким платформам предъявляются следующие требования: 1) охват большого числа разделов олимпиадной информатики, 2) возможность практиковаться на задачах разного уровня сложности с автоматической проверкой решений, 3) доступность с разных устройств и операционных систем.

Однако в имеющихся решениях, по нашим данным, отсутствуют: 1) единая структура обучения, объединяющая теорию, визуализацию алгоритмов и практику в одном месте, 2) наглядная визуализация работы алгоритмов, 3) информация об олимпиадах и преимуществах, которые дают их результаты (например, при поступлении), 4) возможность для учителей и самих учеников создавать собственные задачи, 5) активное сообщество, в котором можно обсуждать решения.

Заявляемый программный продукт позволит решить эти проблемы и обеспечит пользователям широкий функционал, интуитивно понятный интерфейс и удобную систему обучения как для самостоятельной подготовки, так и для работы в классе.

 **[ ЗАКАЗЧИК / ПОТЕНЦИАЛЬНАЯ АУДИТОРИЯ ]**  

Программный продукт может заинтересовать специфичную аудиторию, поскольку рассчитан на подготовку к олимпиадам по конкретному предмету, а именно:

- Учащиеся средней и старшей школы, интересующиеся олимпиадной информатикой, с разным уровнем знаний
  
**[ АППАРАТНЫЕ / ПРОГРАММНЫЕ ТРЕБОВАНИЯ ]**  

Продукт представляет из себя веб-сайт который к моменту сдачи должен запускаться в любом из перечисленных браузеров :
- Firefox 88+
- Chrome 90+
- Edge 90+
  
**[ ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ ]**  

Программный продукт будет предоставлять следующие возможности:
- Cистема аккаунтов
- План по подготовке к олимпиадам
- Визуализация алгоритмов
- Встроенный в сайт компилятор
- Форум
- Подборщик олимпиад 
- Задачи для практики алгоритмов и возможность их решать, оценивающая система
- Возможность добавлять свои задачи на платформу
- Режим учителя, включающий в себя возможность проведения контестов


**[ ПОХОЖИЕ / АНАЛОГИЧНЫЕ ПРОДУКТЫ ]** 

Анализ 3 программных продуктов, которые максимально приближены к заданному функционалу, показал, что:

- VisuAlgo: не является полноценным курсом, не поддерживает русский язык
- Algorithmica: представляет из себя простой учебник, не предусматривает практику
- ACMP: неспособен полноценно подготовить, так как является простым архивом задач
